## 5. 理论-实验一致性

- **能量收缩（Prop D.1/Cor D.3 的动作域实例化）**：LIBERO 离线评测中 chord 场能量
  0.253 vs naive 0.760（3× 收缩），定量验证 L² 收缩；Meta-World 在线轨迹能量与
  交接场能量同向。
- **稳定性条件（λ·L<1）**：交接锚点处 ‖∂ε̂/∂a‖ 有限差分估计 L≈1.0（LIBERO）、
  Meta-World 同量级。λ=0.15 ⇒ λ·L≈0.15<1 处于稳定区；λ 增大到 0.3/0.6 后成功率单调下降
  （0.25→0.08→0.00），**与稳定条件定性一致**。但「技能对可组合性判据」
  （L(s,s′)=L(s)+c‖e_s−e_s′‖ 的分解证明）尚未在实验中形成强闭环——这是理论部分的
  未完成项（§7）。
- **投影不破坏稳定性（新增定理 1）**：投影（clip/限速/平滑均为非扩张算子）后
  LIBERO 拼接 MSE 不升反降（1.489→1.149），与「投影只收缩不放大」一致。

## 6. 总体结论

**方案是否可行**：**可行（带保留）**。
- 核心机制成立：Chord 场在动作空间确实把「高能发散残差场」变成低能传输，
  成功率 3×、能量 3×↓、jerk 22%↓，且该结论在 Meta-World（在线）与 LIBERO（离线，
  真实数据规模）两个域复现。
- 新增模块成立：可行性投影是最扎实的增量（LIBERO 上独立贡献显著）；时间掩码贡献
  方向性为正但弱。
- **保留**：(a) GSC 式能量组合（乘积专家一步重建）在长链上强于扰动式 chord——
  本文的定位应是「低能+有稳定性保证+带物理投影的轻量交接」，而非「最强的交接」；
  (b) 有效时间步平移解释了 chord 增益的相当部分（与复现论文一致），论文必须做
  「chord 平滑 vs 时间步平移」消融并论证 chord 的独立价值（方差降低、与掩码/投影兼容）；
  (c) unseen 组合成功率低——零样本组合在当前小模型上受分布偏移限制。

**理论-实验是否一致**：定性一致（能量收缩、λ·L 稳定区、投影非扩张均有实验证据），
但「技能对可组合性判据」尚无强闭环。

**距 AAAI/CVPR 还缺什么**（按优先级）：
1. **一致性蒸馏修复**（c_skip/c_out 参数化替代 x0 直接预测，避免高噪声区 1/α 放大），
   否则「单步价值」只有 4 步 DDIM 的方向性证据。
2. **unseen 组合成功率**：换更强技能策略（图像观测 CNN-DP 或更大容量）、或把 unseen
   定义为「未见的技能序对但首技能前置满足」（已在用）并加大演示多样性；预期需要
   LIBERO 在线评测（BDDL 成功判定）坐实零样本组合声明。
3. **训练式组合 baseline 补全**：SCaR 式交接正则的实现与对比（当前只有端到端训练基线）。
4. **统计显著性**：关键对比提升至 24-50 回合/任务（当前 12 回合，噪声大）。
5. **理论严格化**：L(s,s′)=L(s)+c‖e_s−e_s′‖ 的证明 + 沿交接轨迹的逐技能对 Lipschitz
   统计（数据已收集在 results 的 lips 字段，需分析脚本）。
6. door-open 场景 DP 数据量不足未训好（40 段），需要更多演示或直接并入 LIBERO
   （其任务天然含 open/close 原语）。
7. 与复现论文（时间步平移）的正面回应消融已做（eff_shift 基线），论文叙述需引用该文。

## 8. 第二轮迭代结果（2026-09-03：三项高优先级改进）

### 8.1 一致性蒸馏修复（②）

**根因（两层）**：
1. 旧实现用 `x0 = (a − σ·ε̂)/α` 直接预测干净动作，高噪声区 α≈0.0026
   使误差放大 ~400 倍，训练初期 loss 发散至 1e20；
2. 改为 CM 标准参数化（`F = c_skip·z + c_out·G`，c_skip=1/(1+σ²)，c_out=σ/√(1+σ²)）
   后 loss 虽收敛但函数错误——诊断发现**训练对构造方向反了**：一致性链必须从
   数据侧（τ=1 边界 F(z,1)=z）锚定向噪声侧传播，旧实现让 target 落在噪声侧，
   任何常值函数都自洽。

**修复后结果**（50k iter、n_levels=12、EMA 0.999、lr 5e-5）：
- 蒸馏损失收敛至 ~0.001（旧实现同样收敛但函数错误，教训：**loss 收敛 ≠ 蒸馏正确**，
  必须以「1 步学生 vs 教师 24 步的采样 MSE / 下游成功率」为验证指标）；
- 学生 1 步 vs 教师 24 步采样 MSE：170.8 → **0.61**；
- **1 步学生在 Meta-World 单技能成功率：reach 1.00 / grasp 1.00 / lift 1.00 /
  carry 0.88 / place 0.88**，与 24 步教师（1.00/1.00/1.00/0.88/1.00）基本持平——
  真正的一步策略蒸馏成立，「单步价值」论证的前提条件已具备。

### 8.2 恢复评测闭环（③，Meta-World）

协议：5 技能链 chord 执行；carry 阶段随机时刻注入「抓握失败」扰动（强制开夹爪 8 步，
物体掉落）；在 carry→place 交接边界以「场能量相对尖峰（>3× 本回合已见边界能量中位数）」
触发重规划（回到 grasp 补抓，限一次）。

| 配置 | 官方成功率 | 送达率（puck 距目标 <0.15） |
|---|---|---|
| clean | 0.92 | 0.92 |
| 扰动 + 无恢复 | 0.08 | 0.50 |
| 扰动 + 场能量重规划 | 0.08 | 0.42 |

结论：
1. **场能量是可靠的免训风险信号**：未扰动边界能量 ~4-9，扰动后尖峰至 30~6×10⁶，
   相对尖峰触发判定准确捕捉扰动（7/12 回合触发）。
2. **恢复机制机械上跑通**：触发后重新 grasp 成功（轨迹跟踪确认重新夹持物体）、
   链式执行至终相并把物体送达目标附近（送达率 0.42）。
3. **官方成功率未恢复**：当前状态空间 DP 的终相放置精度不足（送达时距目标 ~0.075
   vs 官方阈值 0.07）。这是「恢复闭环」的已知限制，对标 HELM 54.2% 恢复率仍差距明显；
   提升路径 = 更强骨干 / 更多演示 / 蒸馏模型 + 终相精度专项调优。

## 9. 第三轮迭代（2026-09-03：审计 + 符号修复 + 优化 + 长跑）

### 9.1 审计发现的关键 bug：B_t 符号反了（本轮最大发现）

逐项核对代码与设计时发现：`nets.b_t_epsilon` 返回 `+γ_max/(2σ)`，
但按我们的约定（τ=1 干净、前向 `z=α·a+σ·ε`、α 随 τ 递增）严格推导：

```
α̇ = α·γ_max/2 > 0,  σ̇ = −α²γ_max/(2σ) < 0
共享 z 上: α·Δa + σ·Δε = 0  ⇒  Δa = −(σ/α)·Δε
Δv = α̇·Δa + σ̇·Δε = (σ̇ − α̇σ/α)·Δε = −γ_max/(2σ)·Δε
⇒ A_t^(ε) = −γ_max/(2σ)   ← 应为负号
```

旧实现把传输场方向整个反掉了（动作块被推向**远离**目标技能的方向）。
此前 λ 被迫调至极小（0.15）且掩码只动 4 步，反方向扰动被后续重采样部分掩盖，
导致「chord > naive」看似成立但整体成功率被系统性压制。

**修复后全局变化**（同一模型、同一协议，仅改 B_t 符号）：

| 配置 | 修复前 5 链 e2e | 修复后 5 链 e2e |
|---|---|---|
| chord（λ=0.3） | 0.25 | **0.64**（36 eps） |
| naive（λ=0.3） | 0.08 | **0.56**（36 eps） |
| LIBERO 离线 chord 拼接 MSE | 1.489 | **1.263** |
| LIBERO 离线 naive 拼接 MSE | 1.785 | **1.379** |

结论：**此前所有轮次的绝对值都被这个符号 bug 低估了；修复后整套「传输场」机制才真正按设计工作**。

### 9.3 新方法 chord_recon（Chord 平滑 + 一步 x0 重建）

动机：energy 模式（GSC 式分数叠加一步重建）有「重建强度」，但未平滑的叠加分数
高能发散，λ=1.0 时 5 链仅 0.208（崩溃）；chord 扰动式有稳定性但强度弱。
chord_recon 对「噪声预测差 Δε̂」做 Chord 时间加权平均后再一步重建：

```
Δε̂_chord = [t·Δε̂(t−δ) + δ·Δε̂(t)]/(t+δ)      # 对原始分数差平滑(无 B_t 放大)
x0 = (z − σ·(ε̂_A + Δε̂_chord)) / α            # 源技能分数 + 平滑修正的一步重建
a ← a + λ·(x0 − a)·mask
```

结果（24 回合）：chord_recon λ=1.0 达 **0.708**（当轮全场最高），λ=0.5 为 0.583；
36 回合回落至 0.639（与 chord 持平）。结论：chord_recon 是「GSC 强度 + Chord 稳定性」
的正确结合点，值得作为论文主方法候选继续打磨（δ/λ 联合标定、更多回合）。

### 9.4 LIBERO 观测升级（object-state 重放数据）

把 env 派生的 object-state（28~112 维，随任务物体数变化）拼入观测，
每任务模型重训后：
- 采样 MSE（24 步）：0.94（旧 9 维模型 1.4；升级前全局模型 12.3）
- **技能进度：0.092 → 0.208（2.3×）**，部分任务 0.42-0.83
- 在线 e2e（BDDL）：仍为 0——长程 BDDL 对当前低维 DP 依然过难

结论：观测升级带来明确的策略质量提升（趋势正确），但离 LIBERO-Long e2e 成功
还有数量级差距；下一步必须上图像观测 CNN-DP / 冻结 VLA 特征（数据集自带
agentview 图像，训练无需渲染，仅评测时渲染）。

### 10.2 清单执行结果

**#2 chord_recon δ/λ 联合标定（8 配置 × 24 回合 + 48 回合验证）**：

**chord_recon 与 chord 持平，不再单独作为主方法**，作为「重建式变体与扰动式
同样有效」的消融证据。

**chord vs naive 汇总（5 组配对对比，合计 164 回合）**：
4 胜 1 平（8 回合组 0.75/0.75），平均差距 **+6.2 分**，方向高度一致但单组
n=48 未达显著（SE≈0.073）。论文表述应为「一致性优势 + 离线机制指标（能量
3×↓、jerk、MSE）」而非单点显著性；如需 p<0.05 需单组 100+ 回合。

**#3 x0 空间无差距的根因（诊断脚本 diag_field.py）**：

- 学生编辑**完全有效**：offline err 6.07 → chord 2.29 / naive 2.36（-63%），
  proj 后编辑量 4.62 = gap 的 76%，饱和率仅 7.8%——「场太弱」假设被否。
- 真因：**cos(R(τ), R(t−δ)) = 0.978（学生）/ 0.982（教师）**——场在 τ 方向
  高度共线，Chord 时间平均近乎恒等（|û_chord| vs |û_naive| = 6.27 vs 6.04，
  差 4%）。一致性训练的自洽性使 F 沿轨迹平滑 → 平滑算子无物可平滑。
- 24 回合确认：chord 0.208 vs naive 0.333（8 回合时两者完全相同）——模式
  间差异为采样噪声级。
- **结论**：Chord 时间平滑是对「多步采样器逐步估计波动」的方差缩减算子；
  自洽 1 步学生已天然平滑，Chord 退化但不伤害（传输编辑本身仍有效）。
  这是方法适用边界的机制性刻画，写入论文 limitations。
- 附带修正：第二轮「1 步学生 5 链 0.40-0.50 超过教师 0.25」的对比被符号
  bug 污染（教师受影响、学生 x0 空间不受影响）。修复后教师 0.56-0.64 >
  学生 0.21-0.50；学生的价值在 NFE（24×↓），等算力对比应为

**#5 L(c,c′) 分解证明（docs/theory_composability.md）**：

- 定理：L_v(c,c′) ≤ |B_τ|·L_ac·d(e(c),e(c′))，d² = d_fam² + d_ground²
  （家族距离 + 接地指令距离的正交分解）；同家族交接严格更易（d_fam=0）。
- 链式：log L_chain ≤ Σ log(1+λL_v) + (K−1)log L_S——误差指数放大但对
  边界可加分解 → 可组合性图上做最小瓶颈路径规划（规划-稳定性接口）。
- P1 已核验：48 回合实测边界 Lip 0.90-1.26，**涉及 grasp 的边界最大
  （1.13-1.26）**，与恢复实验「抓取边界最危险」互证；λL_v ≪ 1 全部安全域内。
- P2/P4（语义距离预测力）当前 one-hot 条件下不可检验（d_fam≡√2 无方差）——
  这构成 v3 工具语义条件的必要性论证，如实标注。
- TAPT 式训练对齐 baseline：**暂缓**——需 VLA 骨干预训练 + 调用对齐后训练
  基建，超出当前算力；以零训练基线（naive/GSC/eff_shift）+ 端到端多任务 DP
  作为对照组合，TAPT 对比留给 v3 VLA 阶段。
