# 可组合性判据 L(c,c′) 的分解证明

对应 SWDP.md §5 定理 2 的严格化。目标：证明交接边界的 Lipschitz 常数可分解为
「同家族项 + 语义距离项」，从而给出调用对 (c,c′) 免训交接的充分条件。

## 1. 记号与假设

- 调用条件 c = (g, z)：工具家族 g + 接地指令 z；嵌入 e(c) = [one-hot(g); enc(z)]，
  enc 为冻结文本编码器（Lipschitz 常数 L_enc，可由有限差分估计）。
- 冻结策略 Q(a, τ, o, c)：噪声预测网络（MLP + FiLM 条件干线）。
- 交接编辑场（eps 空间, 单噪声实现共享）：
  v(a; c, c′) = B_τ · [ Q(z_τ, τ, o, c′) − Q(z_τ, τ, o, c) ]（naive 算子；
  chord 加权平均 û = [t·R(t−δ)+δ·R(t)]/(t+δ) 是 v 的凸组合，Lipschitz 常数
  不超过各分量上界, 见注 3）。
- 交接映射 H(a) = P_C( a + λ·û(a) )，P_C 为凸可行集上的投影。

**假设**：

- (A1) P_C firmly non-expansive（凸集投影的标准性质 ⇒ 1-Lipschitz）。
- (A2) 混合 Hessian 有界：‖∂Q/∂a(·,c) − ∂Q/∂a(·,c′)‖ ≤ L_ac · ‖e(c) − e(c′)‖。
- (A3) FiLM 条件生成器 Lipschitz：‖γ(c)−γ(c′)‖, ‖β(c)−β(c′)‖ ≤ L_film‖e(c)−e(c′)‖。
- (A4) 重采样算子 S_c（DDIM 积分）沿轨迹 Lipschitz，常数 L_S。

(A2)(A3) 对 MLP+FiLM 架构成立的充分条件：每层 a↦h 线性部分 W_k 与 FiLM 调制
逐层复合，∂Q/∂a 只通过 Π(γ_k ⊙ W_k) 依赖 c，故
L_ac ≤ sup‖φ′‖ · Σ_k ‖W_k‖ · (Π_{j≠k}‖W_j‖) · L_film（可由权重范数直接计算上界）。

## 2. 定理（分解）

**L_v(c,c′) := Lip(a ↦ v(a; c,c′)) 满足**

```
L_v(c,c′) ≤ |B_τ| · L_ac · d(e(c), e(c′)),
d(e,e′)² = ‖one-hot(g) − one-hot(g′)‖² + ‖enc(z) − enc(z′)‖²   (欧氏分解)
```

**证明**：v 的 Jacobi 矩阵为 B_τ·[∂Q/∂a(·,c′) − ∂Q/∂a(·,c)]（链式法则, B_τ 为标量
调度系数）。由 (A2)：

‖J_v(a)‖ ≤ |B_τ| · ‖∂Q/∂a(·,c′) − ∂Q/∂a(·,c)‖ ≤ |B_τ| · L_ac · ‖e(c) − e(c′)‖。

对 a 取上确界即得。嵌入差按定义是拼接向量之差，欧氏范数平方 = one-hot 部分差² +
编码部分差²（正交拼接），得距离分解。∎

**注 1（同家族严格更易）**：同家族 c=(g,z), c′=(g,z′) 时 one-hot 部分差 = 0，
L_v ≤ |B_τ|·L_ac·L_enc‖z−z′‖。跨家族至少 d_fam = √2（one-hot 异族）。
**同家族交接的稳定性条件严格弱于跨家族**——这正是「工具家族内共享运动基元」
设计选择的理论依据。

**注 2（B_τ 的调度依赖）**：|B_τ| = γ_max/(2σ(τ)) 随 σ 减小（τ→1）而增大，
故低噪声侧查询的编辑更强也更“敏感”；λ·L_v < 1 的安全域在 τ 上非均匀——
与实验中 τ=0.9 工作良好、更小 τ 需更小 λ 的观察一致。

**注 3（chord 不放大 Lipschitz）**：û = (t·R(t−δ) + δ·R(t))/(t+δ)，
Lip(û) ≤ (t·Lip(R(t−δ)) + δ·Lip(R(t)))/(t+δ) ≤ max_k Lip(R_k) ≤ 上式界。
凸组合只可能收缩（Jensen）。

## 3. 定理（链式误差传播）

K 技能链 a ↦ H_K ∘ S ∘ H_{K−1} ∘ ... ∘ S ∘ H_1 (a₀) 的总 Lipschitz：

```
log L_chain ≤ Σ_{k=1}^{K−1} log(1 + λ·L_v(c_k, c_{k+1})) + (K−1)·log L_S
           ≤ λ·Σ_k L_v(c_k, c_{k+1}) + (K−1)·log L_S
```

**证明**：H = P_C ∘ (id + λû)。对任意 a,a′：
‖H(a)−H(a′)‖ ≤ ‖a−a′‖ + λ‖û(a)−û(a′)‖ ≤ (1+λL_v)‖a−a′‖（用 A1 与 v 的 Lipschitz）。
链式复合取乘积；log(1+x) ≤ x。∎

**含义**：交接误差在链上**指数放大，但放大率对每个边界可加分解**——
长链风险由「最坏边界」主导，可组合性图（节点=调用, 边权=L_v 估计）上
做最短/最小瓶颈路径规划即可**先验地**选择低风险执行顺序。
这是把「规划」与「稳定性」连接起来的接口（Plan-and-Compose 的理论闭环）。

## 4. 命题（投影不放大）

对任意 a,a′：‖P_C(a) − P_C(a′)‖ ≤ ‖a − a′‖（firmly non-expansive）。
故 λ=0 退化、约束集收紧、投影步数增加均**单调不增** L_H——可行性投影与
稳定性不冲突（SWDP.md 定理 1 的局部版本）。
